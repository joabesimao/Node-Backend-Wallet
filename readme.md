# Carteira de Ações
[![License: MIT](https://img.shields.io/badge/License-MIT-red.svg)](https://opensource.org/licenses/MIT)

## Uma API RESTful para gerenciar carteiras de ações, consultar cotações, adicionar posições e acompanhar investimentos.

# 📁Requirements

- ✅ Criar e listar carteiras
- ✅ Adicionar/remover posições (ações) da carteira
- ✅ Consultar ações disponíveis
- ✅ Obter cotações em tempo real (via API externa)

# Installation

  

```bash

git clone https://github.com/joabesimao/Node-Backend-Wallet.git
cd cd Node-Backend-Wallet/
 
npm install
npm start
```

# 🧪 Test

####  To execute this project tests, you must run the following commands:

```bash

 npm test
 npm test:unit
```
